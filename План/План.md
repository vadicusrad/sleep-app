# План приложения для учета и планирования сна ребенка

Дата фиксации договоренностей: 25 октября 2026 года.

## Назначение

Простое приложение для родителя, которое помогает отмечать сон ребенка, рассчитывать ближайшее засыпание и видеть длительности сна и бодрствования без ручного подсчета.

Основные действия должны занимать несколько нажатий на телефоне. Днем родитель записывает события по ходу дня, а прошедшую ночь заполняет утром отдельной формой.

## Как читать план

- **Согласовано** - прямо следует из требований пользователя.
- **Предлагается** - рабочее решение для обсуждения; не считать его утвержденным требованием.
- **Открытый вопрос** - деталь, по которой пока нет окончательного решения.

Подробности интерфейса и технические решения в этих файлах описывают будущую реализацию. Первая локальная реализация создана на согласованном стеке. Команды запуска, проверок и ограничения размещения описаны в [README](../README.md). Предложенные детали могут уточняться по результатам использования.

## Основная логика

Днем: **«Проснулся» → фактическое время → следующее ВБ → время следующего сна → «Уснул» → фактическое время → отсчет сна → «Проснулся»**.

Вечером: **«Уснул на ночь» → фактическое время начала ночи**. Ночью пользоваться приложением не требуется.

Утром: **«Заполнить ночь» → один или несколько интервалов «уснул - проснулся» → общий фактический ночной сон**.

Суточный объем сна считаем от утреннего подъема до следующего утреннего подъема: **СДС + фактический НС**. Период не обязан длиться ровно 24 часа.

Пользователь один раз вводит дату рождения, возраст рассчитывается автоматически. В первой итерации нормы доступны на отдельной странице в виде таблицы; автоматическое сравнение и подсветку откладываем.

После пробуждения можно подтвердить предложенное последнее ВБ или заменить его. Предусмотрена кнопка копирования дневника текстом. Полный прогноз дня, экспорт и импорт в первую итерацию не входят. Целевая платформа - Android, браузер Chrome и установленная PWA.
