# Тихий час

Локальный дневник сна ребенка: дневные события и следующий сон по введенному ВБ, ночные интервалы, комментарии, история и текстовое копирование дневника.

## Запуск

Требуется Node.js 22.12+ или 24+.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. Для локального просмотра на том же компьютере обычно используется http://localhost:5173.

## Проверки и готовая сборка

```sh
npm test
npm run build
npm run preview
```

PWA и service worker проверяются на production-сборке через `preview`, а не на сервере разработки. Для установки на Android и работы с другого устройства приложение необходимо разместить по постоянному HTTPS-адресу. Установка на реальный Android-телефон требует отдельной проверки после размещения.

## Стек

React, TypeScript, Vite, Zustand с persist, React Router, CSS Modules, vite-plugin-pwa. Расчеты покрыты Vitest.

## Данные

Дневник, дата рождения, последнее ВБ и черновики ночи сохраняются в localStorage под ключом `quiet-hour-v1`. Суммы и возраст рассчитываются из исходных данных. Отсчет сна восстанавливается по сохраненному времени, без записи каждого тика таймера.

Данные привязаны к браузеру и адресу приложения, включая порт. Разные адреса локального запуска имеют разные дневники. Очистка данных сайта удаляет записи. При ошибке чтения приложение сохраняет исходную запись и не перезаписывает ее пустым дневником; при ошибке сохранения показывает предупреждение.

Суточный период идет от утреннего подъема до следующего подъема. Сумма сна за него — дневной сон плюс фактические интервалы следующей ночи. Пока ночь не заполнена, итог неполный.

## Возможности первой версии

- Фактические события «Проснулся», «Уснул» и «Уснул на ночь» с исправлением времени и комментариями.
- Ручное следующее ВБ и предложение предыдущего значения.
- Отдельная ночная форма с несколькими интервалами, датами, комментариями и сохранением черновика.
- Дневные, ночные и суточные итоги, история, заметки и копирование текстом.
- Автоматический возраст по дате рождения и справочная таблица 8–18 месяцев.
- Адаптивный интерфейс, манифест, иконки и офлайн-кэш приложения.

Автоматическое сравнение с нормами, полный прогноз, экспорт, импорт и синхронизация в первую версию не входят.

## Публикация на Vercel

Репозиторий: [vadicusrad/sleep-app](https://github.com/vadicusrad/sleep-app). Основная ветка — `main`.

Проект подготовлен для бесплатного Vercel Hobby: Vite, установка зависимостей из lock-файла, проверка тестов перед сборкой и каталог результата `dist`. В `vercel.json` настроены прямые ссылки на страницы приложения и обновление service worker без долгого кэширования.

После подключения репозитория в Vercel изменения в `main` можно публиковать автоматически. Хостинг раздает статические файлы; записи сна не отправляются на GitHub или Vercel и остаются в localStorage устройства.
